How OpenLid Works

Standard user-space tools fail when the clamshell closes. OpenLid intercepts OS-level power assertions cleanly.

01 / macOS KERNEL

IOPMrootDomain Assertion

On macOS, lid closure triggers an interrupt that bypasses user-space assertions. OpenLid modulates pmset -a disablesleep 1 alongside an active kIOPMAssertionTypePreventSystemSleep token so CPUs and disks operate while the LCD backlight rests.

02 / WINDOWS SUBSYSTEM

SetThreadExecutionState & AwayMode

On Windows, OpenLid engages Win32 ES_AWAYMODE_REQUIRED and configures powercfg LIDACTION 0, allowing display standby while preserving full CPU scheduling, network streams, and audio playback.

03 / SECURITY

Zero-Popup Authentication

Elevated power management modifications require privilege. OpenLid sets up a scoped sudoers entry (/etc/sudoers.d/openlid) via Touch ID once, permitting sub-30ms toggles with zero subsequent passwords or popups.

Hardware Safety by Design

Running laptops with the lid closed can trap heat if airflow is obstructed. OpenLid implements automated fail-safes to protect your silicon:

🌡️ Thermal Overheating Breaker

Continuously monitors system thermal pressure. If temperatures escalate to critical levels, OpenLid drops assertions immediately and allows the machine to sleep safely.

🔋 Configurable Battery Floor

Avoid waking up to an empty battery. OpenLid tracks battery levels and disengages sleep bypass when battery drops below your chosen margin (default 15%).

🛡️ Signal Trap Cleanups

Hooks into process signals (SIGINT, SIGTERM, Windows shutdown) to guarantee power settings are cleanly restored to default on exit.
